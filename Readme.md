# 🎯 Number Guessing Game (Java)

## 📌 Description

This is a simple console-based Number Guessing Game written in Java.
The program generates a random number between 1 and 100, and the user keeps guessing until they get the correct answer.

## 🚀 How to Run

1. Compile the program:
   javac NumberGuessingGame.java

2. Run the program:
   java NumberGuessingGame

3. Enter your guesses in the terminal.

## 🧠 Features

* Random number generation
* User input with Scanner
* Looping until correct guess
* Feedback system (Too high / Too low / Correct)
* Attempt counter

## 🛠 Concepts Used

* Variables and data types
* Control flow (if/else, loops)
* Methods and code organization
* Java Random class
* Scanner for user input
